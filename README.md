# Cross-chain Data Collection Toolkit

This repository provides **scripts and documentation** for collecting,
processing, and normalizing **cross-chain blockchain data**.

## Scope
- Cross-chain transaction data
- Event logs and metadata
- Chain-specific normalization

## Repository Policy
- ✅ Scripts, schemas, and documentation are tracked
- ❌ Raw or processed datasets are **NOT** included

## Data Availability
This repository does **not** include any datasets.

- All raw and processed data are excluded via `.gitignore`
- Data sources and access methods are documented under `datasources/`
- Users can reproduce the data collection process using their own credentials
