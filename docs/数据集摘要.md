# 数据集摘要

## 已完整下载的数据集（2026-11-20）

清单日期为 2026-11-20（北京时间）。本轮以下载清单中标记为「完整下载」的条目为范围。

- 共 **101** 个数据集。其中 **58** 个含 **106** 份原始下载归档，另有 **5** 份 DIVE／SCAD 的内层分卷；其余 **43** 个可直接读取。
- 清理后的文件清点为 **6,458,603** 个普通文件、**122.26 GiB**（131,278,204,937 字节）。原压缩包状态为**已解压、校验并清理原压缩包**，合计 19.98 GiB。
- 文件数与字节数来自本地逐文件统计，计入发布包中的说明、代码、多格式副本及保留的复现输入。表的行数按单表计算，可共享同一批样本。报告明确标出的作者口径来自发布说明或论文。
- 「项目或论文」列记录可核实的归属。写为「用途」的条目，其来源未明确关联论文。
- DS181 的复现包内保留 1,557 个压缩件，包内脚本按原路径或校验值读取部分压缩输入。全部内嵌件另在该数据集的 `_expanded_inputs/` 提供解压副本。
- DS070 与 DS098 的发布 SHA256SUMS 对原始分片校验通过，原清单保留用于追溯；解压后的分片用同名前缀的 `.jsonl` 读取。
